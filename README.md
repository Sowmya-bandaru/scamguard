# 🛡️ ScamGuard

**An explainable, multilingual scam message detector for students and everyday users.**

Paste a suspicious SMS or WhatsApp message and ScamGuard tells you whether it looks like a scam, **why**, and what to do next.

🔗 **Live demo:** https://scamguard-fraudbusters.streamlit.app/

---

## The Problem

Every day, people in India receive fake KYC alerts, OTP theft attempts, prize and lottery claims, loan-app offers, parcel-fee requests, and fake job, internship and scholarship offers. Many of these arrive in regional languages or in mixed Hindi, Telugu and English typed in English letters.

Most spam filters are English-first, built for bulk marketing spam, and give no explanation, so users never learn to recognise the next scam. **Students** are especially exposed to fake internship, placement and scholarship fee scams.

## What ScamGuard Does

- **Risk level:** Low, Medium or High, with a risk score.
- **Plain-language reasons:** the exact warning signs found, such as "asks you to share an OTP".
- **Next steps:** what to do, including the 1930 cyber crime helpline and cybercrime.gov.in.
- **Student-focused checks:** job, internship, placement and scholarship fee scams.
- **Hinglish and Roman-script Telugu support** through character-level text features and examples in the training data.

## How It Works

```
Message → lowercase → ┬─ Rule engine (explainable warning signs) ─┐
                      │                                           ├→ Risk score → Level + reasons + advice
                      └─ ML classifier (probability of scam) ─────┘
```

1. **Rule engine (`rules.py`)** checks for seven warning signs:
   OTP/PIN theft, fake urgency, suspicious links, advance fees, prize or too-good-to-be-true offers, KYC/account threats, and student job or scholarship fee scams. Genuine warnings such as "Do not share your OTP" are not flagged.
2. **ML classifier (`train.py`)** uses TF-IDF character n-grams (2 to 5) with logistic regression and balanced class weights. Character n-grams cope with spelling variations and mixed-language text.
3. **Score fusion (`app.py`):** `score = 0.6 × model probability + 0.4 × min(rules triggered / 3, 1)`.
   Score ≥ 0.60 is **High**, ≥ 0.35 is **Medium**, otherwise **Low**. These thresholds are in `risk_level()` in `rules.py` and can be tuned.

## Project Structure

```
scamguard/
├── app.py            # Streamlit web app
├── rules.py          # Rule engine and risk levels
├── train.py          # Trains the classifier and saves model.joblib
├── custom_data.csv   # Team-built labelled messages (text,label: 1 = scam, 0 = safe)
├── requirements.txt  # Python dependencies
└── README.md
```

`model.joblib` is generated by `train.py`. If it is missing, `app.py` trains it automatically on first start, which is what happens on Streamlit Community Cloud.

## Run It Locally

Requires Python 3.9 or newer.

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train the model (creates model.joblib)
python train.py

# 3. Start the app
streamlit run app.py
```

Open the address shown in the terminal (usually http://localhost:8501).

## Training Data

- **`custom_data.csv`:** a small, team-built set of Indian-style scam and genuine messages in English, Hindi and Telugu (written in English letters). Personal details are never included. Team-built messages are given extra weight during training.
- **Optional `spam.csv`:** download the *SMS Spam Collection* dataset (for example from Kaggle), save it as `spam.csv` in the project folder, and `train.py` will include it automatically. It is not included in this repo.

To improve the model, add more rows to `custom_data.csv` in the format `"message text",label` and run `python train.py` again. Add genuine messages too, so the model does not flag everything.

## Deploy on Streamlit Community Cloud

1. Push this repo to GitHub as a **public** repository.
2. Sign in at [share.streamlit.io](https://share.streamlit.io) with GitHub.
3. Create a new app, choose this repo and the `main` branch, set the main file to `app.py`, and deploy.

## Current Limitations

This is a **baseline prototype**, not a production system.

- The dataset is small, so predictions can be wrong, with both false alarms and missed scams.
- Metrics on a tiny test set are not meaningful, so no accuracy claims are made.
- Regional-language coverage is limited to the examples in the training data.
- Links are checked only for patterns, not against live threat databases.
- No messaging-app integration yet.

## Roadmap

- [ ] Larger, consent-based dataset covering more scam types and languages
- [ ] Fine-tuned multilingual transformer (MuRIL or XLM-RoBERTa)
- [ ] Scam category prediction (KYC, OTP, job, lottery, loan app, parcel)
- [ ] Model explanations with LIME or SHAP
- [ ] Feedback button and review queue for new scams
- [ ] WhatsApp or Telegram bot and Android share-sheet integration
- [ ] Evaluation on a held-out set from a different source or time period, reporting precision, recall, F1 and PR-AUC per category

## Privacy and Disclaimer

- Messages are processed to produce a result and are not stored by this app.
- Do not put real names, phone numbers, account numbers or links into the training data.
- ScamGuard gives guidance, not legal or financial advice. Always verify through official channels.
- If you have lost money to a scam, call **1930** or report at **cybercrime.gov.in** immediately.
